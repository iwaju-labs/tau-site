## What is a Timelapse
A time lapse is a video made by capturing frames at set intervals over time, then playing them back at a higher speed. It's commonly used to show long processes &mdash; like studying, designing, coding. The frames are compressed into a short visually engaging clip.

On macOS, there's no built-in method for recording timelapses, so you'll need to to use workarounds or dedicated tools.

## Method 1: Using Photo Booth/QuickTime (basic but limited)
Photo Booth and QuickTime player come pre-installed on every Mac device and can record you and your screen respectively.

### Steps (Photo Booth)
1. Open Photo Booth
2. Switch to Video mode
3. Record yourself working
4. Manually speed up the recorded footage in an editing software

### Steps (QuickTime Player)
1. Open QuickTime Player
2. Click File &rightarrow; New Screen Recording
3. Record your session
4. Manually speed up the footage in editing software

#### Pros:
- Free and built-in
- Simple to use

#### Cons:
- Large file sizes
- No native timelapse support
- Requires manual editing

They both work, they're just not ideal

## Method 2: Using OBS Studio (more control, but more setup)
OBS Studio is a powerful free tool often used for recording and streaming.
### Steps:
1. Install [OBS Studio](https://obsproject.com/)
2. Set up a display capture source
3. Record your screen
4. Export and speed up footage

#### Pros:
- Highly customizable
- Free and widely used
- Many guides online for setup

#### Cons:
- Steep learning curve
- Large file sizes
- Still requires editing in another software after
- Not optimized for timelapse creation

## Best timelapse settings for Mac
If you're not sure where to start, here's a helpful guide for most use cases

**Frame Interval**: The higher it is, the shorter the video will be
**Duration**: You can choose a duration preset or use the "Unlimited" mode which will let you decide when to stop
**Output**: 24FPS or 30FPS (this is usually personal preference)
**Resolution**: Choosing a higher resolution will also increase the file size

or in short \
&rightarrow; shorter intervals = smoother videos
&rightarrow; longer intervals = more compressed, quicker looking videos

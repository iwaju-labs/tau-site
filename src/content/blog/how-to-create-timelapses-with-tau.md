## Payment
Before getting started with Tau, payment is required. Full access to Tau is available with a single purchase of **€25**, and one licence works on all of your devices. After payment you'll be able to download Tau for either macOS or Windows, and you'll receive a license key via email to activate the app.

## Activation
<img src="/blogs/blog-assets/product-activation.png" />

\
When you open the application for the first time, you'll need to use the license key generated on purchase to activate it. Very simple.

## Intro
<img src="/blogs/blog-assets/tau-intro.png" />

\
After activation, you'll be prompted to follow a short intro &mdash; which explains the general flow of the application from setup to export. When your satisfied with that, you're ready to use Tau!

## Setup
<img src="/blogs/blog-assets/timelapse-setup.png" />

\
The first step to using Tau is the setup screen. Here you are free to set data like:
- project name
- duration
- frame intervals
- camera resolution
- camera
and many more options (currently & to be added later).

The setup screen will show you the total number of frames and duration of the final video so you're not left guessing.

When you've completed the setup, you can then move on to starting a recording.

## Recording
The recording will last the duration that was set previously on the setup screen. When that is complete, you can move on to the editor.

## Editor
<img src="/blogs/blog-assets/tau-editor.png" />

\
The editor is still under developed with a lot of features to be desired.
However, right now, you can playback the timelapse, scrub through the recording and add overlays/widgets to customise the final video.

I plan on adding minimal editing features like trimming, and the ability to add sounds/music using audio files later on.

## Export
<img src="/blogs/blog-assets/tau-export.png">

\
Lastly, the export screen &mdash; where you can complete the timelapse creation process.
Here you can select your output format, frame rate, quality and resolution. You can also toggle the watermark if you want to use it or not.

When you export you'll be able to choose what folder the finished timelapse will go.

I hope you have a great experience using Tau!
